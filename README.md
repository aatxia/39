# Manga Tracker

Простий та зручний додаток для відстеження прочитаної манги, створений на React з використанням Vite.

## Функціонал
- **Перегляд списку:** Відображення карток манги з обкладинками та описом.
- **Додавання:** Можливість додати нову мангу через форму.
- **Видалення:** Видалення тайтлів зі списку в один клік.

## 🛠 Технології
- [React](https://reactjs.org/) — UI бібліотека.
- [Tailwind CSS](https://tailwindcss.com/) — для стилізації.
